---
title: Icons
description: Every hand-drawn icon, generated by code from simple shapes.
---

Each icon is a list of shapes on a 48 by 48 grid, traced by a pen that wobbles the corners and bows the edges a little. The same name always draws the same icon. Use it in `<Card icon>`, `<FlowStep icon>`, `<Icon name>` or the `icon` frontmatter key.

Common names from Lucide, Font Awesome and Mintlify also work: `rocket-launch`, `settings`, `magnifying-glass`, `envelope`, `circle-check` and many more map to these 52 drawings. An unknown name is an error that suggests the closest one.
