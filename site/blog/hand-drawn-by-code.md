Wavemark's icons are not files. Each one is a list of simple shapes (lines, polygons, circles, curves) on a 48 by 48 grid. When a page renders, the theme passes those shapes through a pen.

## The pen

The pen does three small things:

1. It moves each corner a few tenths of a unit, so no corner is perfect.
2. It bows each edge slightly, like a hand that is not a ruler.
3. It goes a little past the starting point when it closes a shape, like closing a circle on paper.

The fill uses the same shape with another wobble and a small offset. The result looks like a print slightly out of register: the ink and the color do not line up exactly.

## Determinism

The wobble comes from a pseudo-random generator with a fixed seed, derived from the icon name. The rocket is always the same rocket. That keeps page `ETag` values stable and lets tests compare HTML.

## Motion

Every stroke has a normalized length (`pathLength="1"`). That lets one CSS rule animate any stroke from nothing to complete. When a card enters the screen, its icon draws itself; so do the `<Steps>` markers and the `<Flow>` arrows.

<Quote author="Design note">
The motion is there to show that the page is made of strokes, not to call for attention. Readers who ask for reduced motion see everything already drawn.
</Quote>
